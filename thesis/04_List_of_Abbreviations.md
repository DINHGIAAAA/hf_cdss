# LIST OF ABBREVIATIONS

This list explains short forms used throughout the thesis. Each abbreviation is written in full the first time it appears in a chapter when that helps clarity.

ACEi means Angiotensin-Converting Enzyme inhibitor, a medicine class that relaxes blood vessels and is often used in heart failure. AHA means American Heart Association, a major United States clinical society that publishes heart-failure guidelines. API means Application Programming Interface, a defined way for software components to talk to each other. ARB means Angiotensin Receptor Blocker, another medicine class that lowers blood pressure and protects the heart. ARNI means Angiotensin Receptor-Neprilysin Inhibitor, a stronger related therapy used in many patients with reduced ejection fraction.

BNP means Brain Natriuretic Peptide, a blood marker that rises when the heart is under strain. CDSS means Clinical Decision Support System, software that helps clinicians make safer treatment decisions. CKD means Chronic Kidney Disease, long-term reduced kidney function that affects drug dosing. CPU means Central Processing Unit, the main processor of a computer. CRUD means Create, Read, Update, Delete, the four basic operations on stored data.

EF means Ejection Fraction, the percentage of blood the left ventricle pumps out with each beat. eGFR means Estimated Glomerular Filtration Rate, a lab estimate of kidney filtering ability. EHR means Electronic Health Record, the hospital's digital patient chart. EN means English. ESC means European Society of Cardiology, a European society that publishes heart-failure guidelines. FDA means Food and Drug Administration, the United States regulator for drug labels. FHIR means Fast Healthcare Interoperability Resources, a modern standard for exchanging health data.

GDMT means Guideline-Directed Medical Therapy, the evidence-based set of drug classes recommended for heart failure. GPU means Graphics Processing Unit, hardware often used to run local language models quickly. HF means Heart Failure. HFSA means Heart Failure Society of America. HFrEF means Heart Failure with reduced Ejection Fraction, typically LVEF of 40% or less. HIS means Hospital Information System. HL7 means Health Level Seven, a family of health data exchange standards.

JSON means JavaScript Object Notation, a common text format for structured data. K+ means potassium, an electrolyte that must be monitored with some heart-failure medicines. LLM means Large Language Model, an AI model that reads and writes natural language. LVEF means Left Ventricular Ejection Fraction. MRA means Mineralocorticoid Receptor Antagonist, a medicine class such as spironolactone that also requires potassium and kidney monitoring.

NER means Named Entity Recognition, automatic detection of names such as drugs or conditions in text. NLP means Natural Language Processing, computer methods for understanding human language. NPV means Negative Predictive Value. OAS means OpenAPI Specification. ORM means Object-Relational Mapping. PDF means Portable Document Format. PPV means Positive Predictive Value.

RAAS means Renin-Angiotensin-Aldosterone System, a hormone pathway targeted by several heart-failure drugs. RAG means Retrieval-Augmented Generation, a method that forces a language model to answer using retrieved source texts. RAM means Random Access Memory. RBAC means Role-Based Access Control, permission rules based on user roles. RCT means Randomized Controlled Trial. REST means Representational State Transfer, a common web API style. RRF means Reciprocal Rank Fusion, a method that merges ranked search results from different retrievers.

SGLT2i means Sodium-Glucose Cotransporter 2 inhibitor, a medicine class shown to help many heart-failure patients. SNOMED means Systematized Nomenclature of Medicine, a large clinical vocabulary. SPL means Structured Product Label, the official machine-readable drug label format. SQL means Structured Query Language. SSE means Server-Sent Events, a way for the server to stream updates to the browser. TLS means Transport Layer Security. UMLS means Unified Medical Language System. VI means Vietnamese. XML means Extensible Markup Language.
